# vandinho10.github.io

Site pessoal do **Vanderson Oliveira** hospedado no GitHub Pages.

## Estrutura

```
.
├── index.html            # Página principal (single-page)
├── assets/
│   ├── css/style.css     # Tema dark responsivo
│   └── js/main.js        # Navegação, scroll reveal e interações
└── README.md
```

- **Habilidades** — redes/segurança, telecom, backend, frontend, infra/DevOps e automação
- **Stack** — tecnologias do ecossistema (linguagens, backend, frontend, infra, qualidade)
- **Projetos** — PreventiveCheck, api (Go), docker_projects, frontends Svelte, codectx, loteria e legados

- **Contato** — GitHub, LinkedIn, Instagram e e-mail
